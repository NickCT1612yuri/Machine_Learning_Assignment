# Team collaboration evidence

The assignment awards 5% for "Team Collaboration Spirit" and asks groups to keep
verifiable evidence of real teamwork (photos, meeting videos, discussion minutes).
Put the group's own artefacts in this folder. Nothing here is generated by the code.

Suggested contents:

| File | What to include |
| --- | --- |
| `meeting_YYYY-MM-DD.md` | date, attendees, agenda, decisions, action items (template below) |
| `photo_YYYY-MM-DD.jpg` | photo or screenshot of a meeting / pair-programming session |
| `chat_YYYY-MM-DD.png` | screenshot of a discussion (Messenger, Zalo, Discord, Teams, ...) |
| `progress_report_N.pdf` | the periodic progress reports submitted to the instructor |
| `git_log.txt` | `git log --pretty=format:"%h %an %ad %s" --date=short > reports/evidence/git_log.txt` |

## Meeting minutes template

```markdown
# Meeting YYYY-MM-DD (online / room ...)

Attendees: [Member 1], [Member 2]
Duration: ...

## Agenda
1. ...

## Decisions
- ...

## Action items
| Task | Owner | Due |
| --- | --- | --- |
| ... | ... | ... |
```
