\section{Reproducibility and deliverables}

This submission follows Section~5 of the course assignment. The working layout is:
\begin{verbatim}
notebooks/     Colab front end (Runtime -> Run all)
modules/       assignment_pipeline.py (sole public path); _legacy/ archived
reports/       LaTeX sources (reports/report/), figures, evidence/
outputs/       regenerated features and per-dataset CSV/JSON/PNG
\end{verbatim}

Additional details:
\begin{itemize}
  \item \textbf{Colab front-end.} \texttt{notebooks/text\_classification\_colab.ipynb} embeds the current pipeline; regenerate with \texttt{python notebooks/build\_colab\_notebook.py} after code edits. No personal Drive mount.
  \item \textbf{Modules.} Public API: \texttt{REGISTRY}, \texttt{run\_dataset}, \texttt{make\_report} from \texttt{modules/assignment\_pipeline.py}.
  \item \textbf{PDF report.} This LaTeX document (\texttt{reports/report/main.pdf}), rebuilt with \texttt{make} after syncing figures/tables from \texttt{outputs/full/}.
  \item \textbf{Feature artefacts.} \texttt{outputs/full/features/<dataset>/tfidf.h5}, \texttt{bge\_*.npy}, \texttt{y\_*.npy}.
  \item \textbf{Command line.} \texttt{python -m unittest tests\_pipeline -v}; \texttt{python main.py --quick}; \texttt{python main.py}.
  \item \textbf{Software.} Python~3.x, PyTorch, scikit-learn, transformers, datasets, h5py (see \texttt{requirements.txt}).
\end{itemize}
