\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}

This report presents a reproducible text-classification pipeline for Task~2 of the Machine Learning course assignment. We study three public corpora that stress different aspects of text modelling: \textbf{AG News} (topic classification with strong lexical cues), \textbf{Rotten Tomatoes} (binary sentiment with compositional polarity), and \textbf{Banking77} (77-way fine-grained banking intents). The traditional path uses TF-IDF with Multinomial Naive Bayes, logistic regression, or a linear SVM. The modern path uses frozen BGE-small sentence embeddings with logistic regression. The optional deep-learning path is a TextCNN trained end-to-end from random word embeddings. Features are persisted as sparse HDF5 (TF-IDF) and dense NumPy arrays (BGE); validation Macro-F1 selects configurations, and each family is evaluated once on the held-out test set.

Beyond discrimination metrics we report multiclass Brier scores, expected calibration error (ECE), and accuracy on examples with simple English negation cues versus the remainder. Across the three corpora, ranking among TF-IDF, BGE, and TextCNN shifts with task structure: lexical topic classification favours sparse models, compositional sentiment benefits from contrastive embeddings, and fine-grained intent amplifies the value of pretrained sentence geometry---while a small TextCNN remains a useful but data-hungry baseline. The narrative links these outcomes to conditional independence, margin-based linear classification, frozen transfer, and convolutional sequence models.
